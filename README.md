# УГАДАЙ МЕМ

Веб-проект игры на Node.js, Express, Socket.IO и SQLite.

## Возможности
- Регистрация и вход, пароли хранятся в виде bcrypt-хешей.
- Игровые комнаты на 3–8 игроков, код приглашения, настраиваемые 3/5/7/10 раундов.
- В начале матча каждый игрок получает 6 случайных мем-карт и личную перемешанную колоду для добора.
- Использованная мем-карта уходит в сброс до конца матча; вместо неё игрок берёт следующую карту из своей колоды.
- Ведущий выбирает мем из своей руки, сам пишет ситуацию или генерирует подходящую заготовку; остальные игроки выбирают правильный мем из трёх вариантов.
- В комнате есть полноэкранный режим, а выбор карт и переходы между разделами анимированы.
- +2 очка каждому угадавшему; если никто не угадал — ведущему +3.
- По завершении матча: 10 монет за каждое игровое очко.
- Магазин обложек, покупки и выбор оформления.
- Рейтинг игроков.
- Админ-панель: список игроков, блокировки, изменение монет, удаление комнат.
- SQLite хранит аккаунты, сессии, баланс, инвентарь, блокировки, комнаты и историю матчей.

## Запуск локально
Требуется Node.js 20+.
1. Распакуйте архив и откройте терминал в папке проекта.
2. Установите зависимости: `npm install`
3. Скопируйте `.env.example` в `.env`.
4. Задайте уникальный `SESSION_SECRET` и сложный `ADMIN_PASSWORD`.
5. Запустите: `npm start`
6. Откройте `http://localhost:3000`.

Администратор создаётся при первом запуске, если переменная `ADMIN_PASSWORD` задана. По умолчанию имя администратора — `admin`. Если такое имя уже существует, автоматического повышения прав не происходит.

## Размещение в интернете
Нужен Node.js-хостинг с поддержкой WebSocket и постоянным диском. **Для Render обязательно подключите Persistent Disk** к сервису `ugaday-mem` с Mount Path `/var/data` и задайте Environment Variable `DATA_DIR=/var/data`. В этом каталоге находятся база SQLite и сессии; в ней же хранятся загруженные аватарки. Без подключённого диска Render может очищать данные при новом деплое или перезапуске. В production используйте HTTPS, сильный секрет сессии, уникальный пароль администратора и регулярные резервные копии `data/`.

## Важно
- Активные комнаты восстанавливаются из SQLite после перезапуска. Игрокам нужно снова войти в аккаунт и подключиться по коду комнаты.
- Часть мем-карт использует локальные изображения, часть — внешние изображения из указанных источников. Внешние ссылки могут измениться или перестать работать.
- Это рабочая стартовая версия, а не готовая к большой публичной нагрузке платформа. Перед публичным запуском стоит добавить rate limiting, CSRF-защиту, журнал действий администратора, мониторинг и проверенные резервные копии.
- Для нескольких серверных процессов/реплик понадобится отдельная архитектура для Socket.IO и общего хранилища.

## Игровые столы
В магазине есть отдельная коллекция скинов игрового стола. Стол выбирается независимо от обложек мем-карт и карт ситуаций: игрок может сочетать любые два оформления. Выбор стола и обложек хранится в SQLite в настройках/инвентаре пользователя.


## Сохранение аккаунта и автоматический вход
- После входа браузер получает защищённую cookie сессии на 365 дней по умолчанию. Пока пользователь возвращается на сайт в пределах срока действия cookie, вход автоматически продлевается.
- Срок можно изменить переменной `SESSION_MAX_AGE_DAYS` (от 1 до 3650 дней).
- SQLite-файл аккаунтов и SQLite-хранилище сессий находятся в каталоге `DATA_DIR`. По умолчанию это `./data`; для постоянного диска Render задайте `DATA_DIR=/var/data` и подключите диск с Mount Path `/var/data`.
- Если `SESSION_SECRET` не задан, сервер создаёт случайный секрет в файле `session-secret` внутри `DATA_DIR`. При постоянном хранилище cookie остаются действительными и после перезапусков.
- **Важно для Render Free:** бесплатные Web Services не поддерживают Persistent Disk. На таком тарифе база и сессии могут исчезнуть после перезапуска/деплоя. Для постоянного хранения на Render нужен платный Web Service с диском либо отдельная внешняя постоянная база данных. Уже существующие данные из временной файловой системы нужно отдельно сохранить/перенести до смены хранилища.
